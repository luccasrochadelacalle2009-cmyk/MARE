# Maré – Diário do corpo

App (PWA) para acompanhar emagrecimento: peso, medidas, fotos semanais, água, IMC e meta.
Funciona offline e os dados ficam **somente no seu aparelho** (localStorage + IndexedDB).

## Publicar no GitHub Pages (grátis)
1. Crie um repositório e envie estes arquivos para a raiz.
2. Settings → Pages → Branch `main` / `(root)` → Save.
3. Abra `https://SEU-USUARIO.github.io/NOME-DO-REPO/` no celular.
4. Menu do navegador → "Adicionar à tela inicial" (iPhone: Safari → Compartilhar).

## Rodar local
`python3 -m http.server 8000` e abra http://localhost:8000

## Backup
Ajustes → Exportar gera um .json com dados e fotos. Importar restaura.
